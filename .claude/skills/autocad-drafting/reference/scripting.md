# Generating AutoCAD scripts (.scr) and AutoLISP (.lsp) for the founder

Nothing here has been run inside AutoCAD from this repo, because no AutoCAD seat is available to an agent. Say that when you hand a script over, and have the founder run it on a **copy** of the drawing first.

## Which one to write

| Need | Write |
|---|---|
| A fixed sequence of commands (set up layers, insert a title block, plot every layout) | `.scr` script |
| Anything with selection, loops, arithmetic or a result to report (sum room areas, renumber marks) | AutoLISP `.lsp` |
| Edits an agent should make itself | Nothing yet. That needs a live seat (priced tier: full AutoCAD plus the `autocad` MCP on its COM backend). Until then, generate DXF with `lib/cadgen`. |

**Edition matters.**
- Full AutoCAD for Windows runs both scripts and AutoLISP.
- **AutoCAD LT for Windows runs AutoLISP from LT 2024 on.** Most `vl-`, `vla-` and `vlax-` functions work, but not these:
  - external automation (`vlax-create-object`, `vlax-get-object`, Excel or Word libraries)
  - 3D solid and surface VLA functions
  - ObjectARX or .NET-exposed functions
  - the VLIDE editor
- LT on Mac has no AutoLISP.

## Rules for every generated script

- **Prefix commands with `_`** so they work on any language version of AutoCAD (`_LINE`, `_-LAYER`). Add `.` to get the built-in command even if the office has redefined it (`_.LINE`).
- **Use the `-` command-line form** of commands that would otherwise open a dialog: `_-LAYER`, `_-INSERT`, `_-PLOT`, `_-PURGE`, `_-ATTEDIT`.
- **In a `.scr`, every space and every line break is Enter.** Count them. A trailing blank line ends the last command. Wrap a path that contains spaces in double quotes.
- **Never rely on interactive object snaps.** Set `OSMODE` to 0 at the start and restore it at the end, so typed coordinates land exactly.
- **Wrap the work in undo marks** so the founder can take back everything in one step: `_.UNDO _Begin` … `_.UNDO _End`.
- **Use the drawing's own units.** Check `INSUNITS` first. A script written for metres draws 1000× too small in a mm drawing.
- **Use plain ASCII in file names.** Keep Turkish characters inside strings only, and save `.lsp` and `.scr` files as UTF-8 (AutoCAD 2021+ reads UTF-8 LISP files).

## `.scr` example: create the department's layers

```
_.UNDO _Begin
_-LAYER _New A-WALL,A-WALL-INTR,A-GLAZ,A-DOOR,A-ANNO-DIMS,A-ANNO-TEXT,A-ANNO-TTLB

_-LAYER _Color 7 A-WALL _Color 8 A-WALL-INTR _Color 4 A-GLAZ _Color 3 A-DOOR _Color 1 A-ANNO-DIMS _Color 2 A-ANNO-TEXT _Color 7 A-ANNO-TTLB

_.UNDO _End
```

The blank line after each `_-LAYER` line ends that command. Before using the colours above, check them against the receiving office's CTB (see SKILL.md §5), because in a CTB colour decides pen weight.

## AutoLISP template

Every generated routine follows this shape:
- an error handler
- saved and restored system variables
- one undo group

```lisp
;; <NAME>.lsp -- <what it does>. Generated by Sirketim architecture dept.
;; Untested inside AutoCAD by its author: run on a copy first.
(defun c:<NAME> (/ *error* old-cmdecho old-osmode)
  (defun *error* (msg)
    (if old-osmode (setvar "OSMODE" old-osmode))
    (if old-cmdecho (setvar "CMDECHO" old-cmdecho))
    (command-s "_.UNDO" "_End")
    (if (not (wcmatch (strcase msg) "*CANCEL*,*QUIT*,*EXIT*"))
      (princ (strcat "\nError: " msg)))
    (princ))
  (setq old-cmdecho (getvar "CMDECHO") old-osmode (getvar "OSMODE"))
  (setvar "CMDECHO" 0)
  (setvar "OSMODE" 0)
  (command "_.UNDO" "_Begin")
  ;; ... work ...
  (command "_.UNDO" "_End")
  (setvar "OSMODE" old-osmode)
  (setvar "CMDECHO" old-cmdecho)
  (princ))
```

## Example: total area of selected closed polylines (alan hesabı)

```lisp
;; ALANTOPLA -- sum the areas of selected CLOSED lightweight polylines.
;; Untested inside AutoCAD by its author: run on a copy first.
(defun c:ALANTOPLA (/ ss i tot u)
  (setq tot 0.0 i 0)
  ;; (-4 . "&") (70 . 1) = closed bit set, whatever other flags are present
  (if (setq ss (ssget '((0 . "LWPOLYLINE") (-4 . "&") (70 . 1))))
    (progn
      (repeat (sslength ss)
        (command "_.AREA" "_Object" (ssname ss i))
        (setq tot (+ tot (getvar "AREA")) i (1+ i)))
      (setq u (getvar "INSUNITS"))
      (princ (strcat "\n" (itoa (sslength ss)) " polylines, total "
                     (rtos tot 2 3) " square drawing units"
                     (cond ((= u 4) (strcat " = " (rtos (/ tot 1000000.0) 2 2) " m2"))
                           ((= u 5) (strcat " = " (rtos (/ tot 10000.0) 2 2) " m2"))
                           ((= u 6) " (= m2)")
                           (T " (INSUNITS not set: unit unknown)")))))
    (princ "\nNo closed polylines selected."))
  (princ))
```

How to use it: `APPLOAD` the file, run `ALANTOPLA`, select the room outlines. To get outlines from walls, run `BOUNDARY` (pick inside each room) first.

**This is a measurement aid, not the official emsal calculation.** The emsal calculation follows the method in `zoning-compliance-tr`: itemised, with exclusions.

## Handing a script over

When you give the founder a script, tell them:
- the file name
- what it changes
- that it is untested in AutoCAD
- how to run it: `SCRIPT` for `.scr`; `APPLOAD` and then the command name for `.lsp`
- how to undo it: one `U`, because of the undo group
