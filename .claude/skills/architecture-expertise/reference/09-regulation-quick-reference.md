# Turkish regulation quick reference

This is the **one place** where regulation numbers live in this skill. The other reference files point here instead of repeating figures, so an amendment needs changing once. Turkish building regulations change often. Since August 2025 alone:
- **Planlı Alanlar İmar Yönetmeliği:** amended 13.08.2025, 14.01.2026 (RG 33137) and 01.07.2026 (RG 33297).
- **Sığınak Yönetmeliği:** rewritten 07.11.2025 (RG 33070).

**How to read the "Status" column:**
- **search-verified 2026-10-05:** found in at least one search result quoting the text or a professional summary, on the date shown. Good enough to plan with. **Not good enough to cite in a deliverable.** Read the current official text first; see `zoning-compliance-tr` for the citation rule.
- **repo-verified:** read from the official text during earlier project work and recorded in this repo.
- **verify:** a well-known value that was not confirmed this session. Treat it as a pointer only.

Official text: https://www.mevzuat.gov.tr. MevzuatNo values are in `zoning-compliance-tr/SKILL.md` §2. The Gürültü Yönetmeliği is MevzuatNo 23616.

## Energy, insulation, acoustics

| Topic | Value | Status |
|---|---|---|
| Nearly zero-energy building (YSEB) | Required since 01.01.2025 for total construction area ≥ 2,000 m² (was ≥ 5,000 m² from 2023). EKB at least class B, renewable share ≥ 10% (was 5%). | search-verified (Bakanlık news item); verify the details |
| TS 825:2024 (thermal insulation standard; paid TSE document) | Turkey divided into **6** degree-day zones (was 4), with roughly 20–40% lower U-values. Secondary sources quote wall U from about 0.45 (zone 1) down to about 0.25 W/m²K (zones 5–6) and windows around 1.8 W/m²K. | search-verified (secondary); **verify the zone and the table for each project** |
| Gürültü Yönetmeliği (MevzuatNo 23616) | New buildings: at least sound-insulation **class C**. Change of use or major renovation of existing buildings: at least class D. Class limits (D'nT,w, L'nT,w) are in the annexes. | search-verified |

| Topic | Value | Status |

| 2026 unit costs (RG 03.02.2026 / 33157, valid from 01.01.2026; KDV excluded; 15% overheads and 10% contractor profit included) | III-A 19,800 TL/m². **III-B (housing up to 21.50 m) 21,050 TL/m²** (2025: 18,200).
