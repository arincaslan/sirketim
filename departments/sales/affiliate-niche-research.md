# Affiliate Niche Research — Second Site (parallel to carbide-tipped tools)

Status: research only. No affiliate program signup, no domain registration, no site built. This is a
recommendation for the founder to decide on.

## Context

An earlier review (not this doc) evaluated **carbide-tipped/machining tools** as an affiliate niche and
found it worth keeping but structurally weak on three dimensions: real search demand exists, but (a)
commission is low (~3% typical), (b) the review-site competitive set is saturated with long-tenured
incumbents, and (c) winning would require out-writing/out-authoritying entrenched specialists — not a
fight Sirketim's actual strengths (design/build quality) help with. The founder decided to keep that site
running anyway and add a second, better-fit niche in parallel.

This doc evaluates candidate niches against the same four dimensions and recommends one.

## Recommendation: #1 — niche/indie perfume "dupes" and comparison content

This is the only candidate that clears all three of the dimensions carbide-tipped tools failed on, at the
same time:

1. **Commission**: dedicated fragrance-retailer affiliate programs (Scentbird ~14%/45-day cookie, Dossier
   up to ~20%, MicroPerfumes ~15%) run 3-6x carbide tools' ~3% and Amazon's typical 1-4%, with cookie
   windows (30-45 days) far longer than Amazon's 24-hour window — more time for a reader to convert after
   the visit.
2. **Competitive gap, not just lower competition**: the category's dominant authority site (Fragrantica)
   has a well-documented, community-acknowledged design and UX problem (ad-cluttered, "looks like 2009"),
   and most of the rest of the visible content is brand-owned promotional blogs rather than neutral,
   well-built comparison sites. That's a real, verifiable opening for a well-built neutral comparison
   site — not a guess that competition is merely "less bad" than carbide tools.
3. **Design is the actual differentiator, not just better writing**: Sirketim already has two fragrance
   e-commerce templates built (`products/web-templates/fragrance-store/`,
   `products/web-templates/fragrance-store-2/`). The component work, scent-family visual language, and
   product-photography-driven layout patterns from those builds transfer directly to affiliate content
   formats this niche currently lacks — visual scent-note/accord comparisons, a "smells like X" matcher,
   clean side-by-side layouts — versus the outdated tables and text walls that currently rank.
4. **Search intent is real and growing, not flat**: the "dupe" trend is actively TikTok-driven and
   expanding in 2026 (multiple competing "best dupes 2026" pages published this year across brand blogs
   and lifestyle media), unlike a mature, flat category.

**Runner-up**: pet tech gadgets (#2) — better commission terms than Amazon defaults and a genuinely newer
product category with a still-open comparison layer, but no existing Sirketim design-asset overlap, so it
would win on content/SEO alone rather than design differentiation — the same failure mode being avoided.

**Explicitly not recommended**: scented candles / general home fragrance (#5) and red-light
therapy (part of #3) — both repeat carbide tools' core problem (entrenched, well-resourced incumbents
already own the head terms), just in a different vertical.
