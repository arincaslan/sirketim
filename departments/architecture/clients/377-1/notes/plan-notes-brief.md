## Bottom line: what's actually buildable at 377/1

- **Footprint**: capped by TAKS at 178.32 m² (0.25 × 713.26 m²). The project's current design sits at 178.02 m², essentially the maximum legally allowed.
- **Floors**: 4 above-grade floors (zemin + 3 normal kat) plus 1 basement level and a roof-level piyes that doesn't count as a 5th floor — all already established and unchanged by this read.
- **Total floor area (KAKS)**: capped at 713.26 m². Using the project's own already-published per-floor footprint figures, the current design uses roughly **694 m² — about 97% of the cap**, deliberately close to the ceiling but not over it.
- **Height**: no stated meter limit on either source document — height is governed entirely by the 4-floor count. The project's own working estimate (14.65 m to the eave) is unaffected by anything found in this pass.
- **Setbacks**: front 5 m, side 3 m each, rear 3 m (confirmed straight from source, unchanged).
- **Parking**: 1 stall per apartment, no local override found — unchanged.

None of these headline numbers change as a result of this pass. What follows is the answer to the specific question this pass was commissioned to answer.

## The missed bonus — found, checked, and it does not apply here

There is exactly one item in the plan notes that grants extra floor count without a formal plan amendment: **item 2.12**. It lets a parcel add **1 extra floor** (without increasing KAKS — it works by lowering the footprint, not by adding floor area) — but only for parcels whose **zoned TAKS is already 0.30 or higher**, with a few additional conditions (3+ floors already, no geological-report restriction, no floor-count plan amendment already used since 2004).

**377/1's zoned TAKS is 0.25 on both official parcel documents — below the 0.30 threshold. This bonus does not apply here.** Even setting the threshold aside: the bonus explicitly does *not* increase KAKS/total floor area — it only lets you trade footprint for floor count while total buildable area stays exactly the same. So even in the hypothetical case where a parcel did qualify, it would not be a "more square meters" bonus — it would only reshape the same square meters into an extra, thinner floor.

There is a second, separate item that does grant both an extra floor *and* extra KAKS at the same time — **item 4.2.64** — but it's aimed at multi-story parking-garage buildings: it requires a **minimum 500 m² footprint**, with every floor above the ground floor built entirely as parking. 377/1's TAKS-capped footprint tops out at 178.32 m², well under a third of that threshold, and the building isn't a parking structure. **This one doesn't apply either.**

No other item in the plan notes grants additional floor area, additional floor count, or additional height for a parcel with 377/1's actual facts (Konut Alanı, Ereğli Mahallesi, single-frontage, TAKS 0.25, not part of any special zone). Checked and confirmed clean on a second, dedicated pass through every numbered item.

## Height bonuses — none found

Beyond the two items above (neither of which applies), nothing else in the 95 numbered items adds height or floor count for this parcel's facts. The roof allowance already known and used (mahya ≤5.50 m above the top floor's slab, item 4.2.32) is the only height-related flexibility that actually applies, and it's already fully accounted for in the project's current design.

## Parking exceptions — none found

Nothing in the plan notes reduces the per-apartment stall count, waives it for this location, or offers a transit/proximity-based exception. The 1-stall-per-apartment figure the project already uses comes from the national Otopark Yönetmeliği, and Karamürsel's own plan notes don't add or subtract from it for 377/1's situation. (The plan notes do describe *where* parking can go — basement, mekanik/katlı otopark, etc. — none of which changes the required count.)

## Other things worth knowing (not envelope-changing, but real)

- **The ground floor could legally include a shop or clinic use, not just residential.** Item 4.2.2 allows ground-floor dükkan/sıhhi müessese use on parcels fronting a road ≥10 m wide — Selçuk Bey Caddesi is 12 m, so this qualifies. The current design doesn't use this (pure residential ground floor + shared lobby), and this pass isn't recommending a change — flagging it only because it's a real, available option the founder should know exists.
- **A possible extra practical margin inside the existing 1.00 KAKS cap, via how floor area is technically measured — not a new allowance.** Item 4.2.17 ("Emsal Hesabı Tanımı") is the official method for computing floor area toward KAKS: elevator shafts, fire stairs, and light/air shafts are fully excluded, and on top of that, up to 20% of each floor's remaining area (halls, stairs, balconies, floor gardens, entry lobbies, etc.) is also excluded. This method hasn't been cited anywhere in this project's files so far — the KAKS check currently sums whole footprint areas. Applying this exclusion properly could mean the real usable margin inside the 1.00 cap is somewhat larger than the ~3% currently shown — this is a measurement-method point, not a new bonus square meter, and would need to be run through the actual CAD numbers to quantify (not done in this pass, since this was a documents-only task).
- **A source-document oddity, for completeness**: the plan notes use the item number "4.2.17" twice, for two unrelated rules (the floor-area-calculation method above, and a separate rule about lot coverage on unspecified-TAKS attached-building blocks). Neither issue affects 377/1 — the second one only applies to bitişik (attached) nizam parcels with no TAKS stated, and 377/1 is ayrık (detached) with TAKS explicitly stated at 0.25. Flagged only so nobody is confused seeing the same item number cited for two different things later.
- **Both parcel-specific documents (`imardurumu.pdf`, `minuspalityimardurumu.pdf`) were re-read directly this pass and confirm the same figures already on file** (TAKS 0.25, KAKS/Emsal 1.00, Kat Adedi 4, Ayrık, front 5 m, side 3 m, arka bahçe/height blank, jeoloji ÖA-5.1, parcel area 713.26 m² with "tapu alanı esastır" flagged). No additional numbered constraints appear on these two documents beyond what's already in the plan notes — they're short factual/graphic sheets, not a second source of hükümler.
