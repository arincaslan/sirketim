# Products

Standalone digital/physical products, sold on marketplaces (Etsy, Gumroad, etc.), independent of any client relationship. See `../departments/sales/CLAUDE.md` for the marketplace strategy and priority order.

- `web-templates/` — generic Next.js/Tailwind site templates, one folder per template.
- `architecture-digital-plans/` — generic floor plan packs (DXF/SVG/PDF), not tied to any real client's deed.
- `architecture-prints/` — print-on-demand-ready art (blueprint/line-art style) derived from generated floor plans/renders.
- `affiliate-sites/<niche-slug>/` — Sirketim-owned affiliate/SEO content sites (buying guides, comparisons, reviews with affiliate links), one Next.js project per niche. Different from the other three lines: not sold on a marketplace, revenue comes from ongoing affiliate commissions/ads on the live site itself — closer in kind to an internal capital project (see `shared/clients.md`'s "Internal" entries) than a one-time product sale, but grouped here because it's built on the same web-templates foundation and self-contained-per-project convention. See `departments/web-development/reports/affiliate-sites-technical-plan.md` for the technical foundation (content format, sitemap/robots, JSON-LD, analytics wiring, affiliate-link pattern, shared kit — actually built at `departments/web-development/lib/affiliate-site-kit/` as of 2026-08-25) and `departments/content/CLAUDE.md` for the content-production pipeline that feeds it. `affiliate-sites/fragrance-dupes/` ("PARFUMOZA") is built as of 2026-08-25 — see its own `DESIGN.md` for the design direction and `README.md` for what's implemented; local build only, not deployed, no real affiliate-program enrollment, all content fixtures. Niche 1 (carbide-tipped tools) is confirmed but not yet scaffolded.

Each product folder should contain the sellable files plus a `listing.md` (generated by the `product-listing` skill) with title, description, tags, and pricing for each target marketplace.
